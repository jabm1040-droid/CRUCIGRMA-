🧩 Crucigrama: Procesamiento Profundo

El procesamiento profundo significa comprender, analizar y relacionar la información para lograr un aprendizaje significativo.

Instrucciones:
1. Escribe tu nombre.
2. Lee las pistas.
3. Completa el crucigrama escribiendo las respuestas sin tildes.
4. Presiona Comprobar respuestas para conocer tu resultado.

Crucigrama

Pistas

1. Capacidad de concentrarse en una información o actividad específica.
2. Proceso de examinar información para comprender sus partes y relaciones.
3. Proceso de pensar cuidadosamente sobre una experiencia o información.
4. Proceso mediante el cual una persona adquiere conocimientos y desarrolla habilidades.
5. Capacidad de almacenar y recuperar información.
6. Capacidad de entender el significado de una información.
7. Conjunto de información y saberes adquiridos mediante el estudio o la experiencia.
